# 행운핑 (프론트엔드)

함께 하는 작은 활동으로 일상을 돌보고, 힘든 날엔 실제 도움으로 이어주는 모바일 웹앱(PWA).

- 매일 기분을 한 번 고르고, 각자 작은 미션을 하며, 친구·온라인·1인 그룹과 캐릭터를 함께 키운다.
- 주 1회 마음 점검과 기분 흐름에 따라 실제 공공 지원(상담·센터·바우처)으로 이어준다.
- 도움받기 탭은 계정 없이, 인터넷이 끊겨도 열린다.

기준 문서: 서비스 기획서, MVP PRD, API 명세(api.md), 사용자 흐름(UserFlow.md), 아키텍처, ERD, Figma 「행운핑」 페이지(앱 화면 1~27).
작업 경과와 결정 사항은 [docs/작업기록.md](docs/작업기록.md)에 있다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npx vitest run   # 규칙 단위 테스트 + 목업 서버 계약 테스트 + http 클라이언트 테스트
npm run build    # 타입 검사 + 프로덕션 빌드 + 서비스 워커
npm run lint
```

### 실서버 연결

기본은 기기 안의 **목업 서버**다(api.md와 같은 응답·에러 코드). 백엔드가 준비되면 `.env`만 바꾼다.

```bash
# .env
VITE_API_MODE=http                      # mock(기본) | http
VITE_API_PROXY=http://localhost:8080    # 개발 서버가 /api를 넘길 백엔드 주소
```

화면과 API는 같은 도메인 `/api/v1`, 세션 쿠키(`hp_session`) + CSRF(`XSRF-TOKEN` → `X-XSRF-TOKEN`).

## 폴더 구조

```
src/

  app/          라우터, 레이아웃·가드, 진입 규칙(entry.ts), 모바일 프레임
  pages/        화면 (launch, onboarding, groups, mission, checkin, help, records, collection, my)
  components/   공통 UI, 캐릭터(마스코트 SVG·단계 표시), 그룹 카드, 탭바
  features/     규칙(순수 함수: 성장·기분·미션·점검·도움 필터) + 기능 컴포넌트(기분·점검 팝업, 미션 패널)
  device/       기기에만 두는 데이터: 선택 정보·추억 기록(IndexedDB), 화면 상태(localStorage),
                다중 계정(accounts.ts)·스냅샷(snapshot.ts)·저장 잠금(persistence.ts)
  data/         미션 주제 20쌍, 도움받을 곳 시드, 점검 문항, 감정·핑·지역
  services/     웹 푸시 권한·구독
  styles/       토큰, 전역 스타일
```

## 시연 (목업 서버)

마이페이지 › 시연 도구 (목업 모드는 항상, 실서버는 `GET /me`의 `isDemo`가 true일 때만):
- **시연 데이터 불러오기 (소은)**: 지금 계정을 보관하고 '시연 계정'으로 바꾼다. 서울 마포구 대학생 26세, 친구 그룹 '우리 셋', 온라인 그룹 '아침 산책단'(5명 중 4명 완료, 49.8 → 소은 완료 시 50.2로 3단계)
- **시연 종료** (시연 계정일 때만): 시연 계정을 지우고 시연 전에 쓰던 계정으로 돌아간다. 돌아갈 계정이 없으면 시작 화면
- **하루 넘기기 / 일요일 19시로 / 실제 시각으로**: 시연 시계 (`PUT /demo/clock`). 날짜를 바꾸면 홈으로 가서 기분 팝업부터
- 초대 코드 시연: `HAPPYPNG`(참여) · `EXPRDCDE`(만료) · `FULLGRPS`(가득 참)

## 기기 저장 구조와 다중 계정 (목업 모드)

| 저장 위치 | 키 | 내용 |
| --- | --- | --- |
| localStorage | `haengunping:mock-server:v2` | 목업 서버 상태 (계정·그룹·미션·기분·핑·시연 시계) |
| localStorage | `haengunping:device:v1` | 기기 화면 상태 (온보딩 단계, 기분 팝업 날짜, 내가 남긴 핑 날짜, 캐릭터 개인 별명 등) |
| localStorage | `haengunping:cache:*` | 오프라인용 마지막 응답 (그룹·오늘 미션·me) |
| IndexedDB `haengunping-device` / `kv` | `profile` | 맞춤 도움 정보 (생년월일·지역·하는 일) — 서버로 보내지 않음 |
| IndexedDB | `memory:YYYY-MM-DD` | 추억 기록 (사진 data URL·한 줄 메모·미션 문구) — 서버로 보내지 않음 |
| IndexedDB | `account:{id}` | 보관된(지금 쓰지 않는) 계정의 스냅샷 |
| localStorage | `haengunping-accounts` | 계정 목록·지금 계정 (스냅샷에 들어가지 않는 별도 키) |

- **지금 계정**은 위의 원래 키를 그대로 쓰고, 다른 계정은 `account:{id}` 스냅샷으로 보관한다.
- **전환**: 지금 계정 보관(다시 읽어 확인) → 목록의 지금 계정 변경 → 비우기 → 고른 계정 되살리기 → 보관본 삭제 → 새로 열기. 도중에 멈추면 다음 실행 때 `initAccounts`가 보관본으로 되살린다.
- **처음 실행**: 지금 있는 계정을 등록만 한다(데이터 이동 없음). 예전 시연 백업(`backup:demo`)은 보관 계정으로 바꾼다.
- 실서버는 로그인 쿠키(`hp_session`, HttpOnly)를 화면 코드가 바꿀 수 없어 계정 관리를 숨긴다 (계정 전환 API 필요).

## 백엔드 연동이 남은 부분

코드에 `[백엔드 연동]`으로 표시되어 있다. 요청서: 「행운핑 백엔드 확인 요청」(11-17), 「행운핑 API 요청서 (2차)」(11-17).
- `GET /missions/today`의 `minutes`·`place`·`size`: 백엔드 수용(11-16 회신). 목업 반영 완료, 실서버 연동 뒤 기기 임시값 제거
- `GET /me`의 `isDemo`, 새 에러 코드 3개(`MALFORMED_REQUEST`·`METHOD_NOT_ALLOWED`·`INTERNAL_ERROR`)의 상태 코드: 명세 확인 요청
- 내가 남긴 핑 조회(`GET /me/records`에 `pings`): 요청 — 지금은 '이 기기 기준'으로 셈
- 캐릭터 성장 기록(`.../characters/{id}/history`): 기획 보류, 목업 데이터로 만들지 않음
- 캐릭터 `kind` 값 목록과 `GET /groups`의 `characterId`: 요청
- 다중 계정 실서버 지원: 계정 전환 키 + 세션 전환 API 필요
- 웹 푸시: VAPID 공개키가 비어 있으면 권한 요청까지만 동작

## 변경 내역

### 2026-11-17

**백엔드 회신 반영**
- `ApiErrorCode`에 `MALFORMED_REQUEST`·`METHOD_NOT_ALLOWED`·`INTERNAL_ERROR` 추가, 본문이 없거나 JSON이 아니면 상태 코드로 판단(401·405·5xx)
- `403 CSRF_INVALID`를 받으면 새 쿠키로 한 번만 다시 보냄
- 시연 도구는 시연 계정(`GET /me` `isDemo`)에만 (목업 모드는 항상)

**19개 항목 개선**
- 맞춤 도움 정보 사는 곳: 모든 시·도에서 시·군·구 선택 (2026-07 인천 개편 반영, 예전 직접 입력값은 '(입력한 값)'으로 보존)
- 안내 문구 문장마다 줄바꿈, 마이페이지 메뉴 정리('내 정보' 하나로, 메뉴는 제목만)
- 추억 기록: 미션 완료 화면에서 사진 + 한 줄 메모(40자), IndexedDB 저장(예전 localStorage 사진 자동 이전), 목록·상세·고치기·지우기. '적기' 미션은 적을 칸을 먼저 보여 줌
- '벌써 했어요' → '이미 했다면 바로 완료하기', 밖/안 미션이 서로 대신하는 선택지임을 표시
- 주차 표기 '11월 첫째 주 (11.2 ~ 11.8)'(목요일이 속한 달 기준), 이번 주는 '이번 주 (범위)'
- 마음 점검 진행률: 바는 답한 문항 수, 위치는 'n번째 문항 / 4'
- 캐릭터 '나만 보는 별명'(기기 저장, 성장 과정 화면 오른쪽 위). 내 기록에는 키우는 캐릭터만
- 그룹 화면: '그룹 전체 오늘 N명 중 M명', '나 · 내 이름 · 오늘 미션 완료/아직', '그룹이 오늘 받은 핑', 구성원 목록과 그룹 바꾸기
- 목업 시드의 횟수형 미션 크기(MIS-04), 내 기록 로딩 중 0 표시, 미션 크기 안내 조사 오류

**화면·흐름**
- 하단 탭·제목 '마이' → '마이페이지', '계정은 이 기기에만 있어요' 문구 제거
- 하루 넘기기·일요일 19시로: 새 날짜를 받은 뒤 홈으로 → 기분 팝업이 바로 뜸
- 반응형: 앱 너비 최대 440(Pro Max), 좌우 여백 `clamp(16px, 5.1vw, 22px)`, 온보딩 제목과 '도움받기' 겹침 수정. 320·360·375·390·393·414·440에서 주요 화면·바텀시트 점검
- 기록 동의: 체크박스 대신 '동의하고 시작하기'를 바로 누르는 주 버튼 (미리 체크·자동 동의는 쓰지 않음)

**다중 계정·시연 (목업 모드)**
- 계정 관리(`/accounts`): 지금 계정, 저장된 계정 목록, 전환(확인), 새 계정 만들기, 보관 계정 삭제(동의 체크)
- 시연 데이터 = 시연 계정, 시연 종료 = 시연 전 계정으로 복귀

**오류 수정**
- 완료 화면에서 사진·메모를 저장하면 추억 기록 상세로 가 버려 핑을 남길 수 없던 문제 (완료 화면으로 돌아오고 고른 핑 유지)
- 내 기록에서 횟수형 미션 크기가 '2번'처럼 보이던 단위 오류 ('2개')
- 바텀시트 안 입력칸에서 글자마다 포커스가 빠져 입력이 끊기던 문제 (별명·그룹 이름·계정 삭제 확인)
