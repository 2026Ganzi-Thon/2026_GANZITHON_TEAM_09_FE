## 1. 새 요청 — API 필드 추가

| # | 요청 | 왜 필요한가 (11-17 변경) | 지금 프론트 처리 |
| --- | --- | --- | --- |
| 1 | `GET /me/records?month=` 응답에 `pings` 추가 (그 달에 내가 핑 남긴 날짜 목록, 예: `["2026-11-03", ...]`) | 내 기록에 '이번 달 내가 남긴 핑' 칸이 생김 | 이 기기에서 보낸 날만 셈. 기기를 바꾸거나 저장소를 지우면 0 |
| 2 | `GET /groups` 목록의 `character`에 `characterId` 추가 | '나만 보는 캐릭터 별명' 추가. 별명을 그룹+캐릭터 ID로 기기에 저장함 | 목록에 ID가 없어 그룹 상세(`GET /groups/{id}`)를 한 번 더 부름. 다음 캐릭터로 별명이 넘어가지 않게 ID 없으면 별명 안 붙임 |
| 3 | `GET /me`에 `isDemo: boolean` 추가 | 마이페이지 시연 도구(하루 넘기기·일요일 19시로·실제 시각)를 시연 계정에만 보이기 | 값이 없으면 시연 계정 아님으로 봄 → 실서버에서는 시연 도구가 안 보임 |

## 2. 정해 주기 바람 / 확인

1. **실서버 시연 범위.** 아래는 지금 목업 서버에만 있음. 실서버 시연에서 필요한지 정해 주기 바람.
   - 시연 데이터 불러오기(소은 계정·그룹 2개·지난 기록), 시연 종료(시연 전 계정으로 복귀)
   - 온라인 매칭 '대기부터' 모드(20초 뒤 배정)
   - 시연용 초대 코드 3개(참여·만료·가득 참)
   - 필요 없으면 실서버 시연 도구는 `PUT /demo/clock`만 쓰는 것으로 확정함.
2. **서울 25개 구 정신건강복지센터 연락처.** `/help/items`의 `LOCAL_CENTER` 항목에 검수된 주소·전화를 넣어 줄 수 있는지. 지금은 이름만 있고, 전화 버튼은 1577-0199로 대신함.
3. **웹 푸시 발송 확인.** VAPID 키 말고 발송 쪽도 구현 범위인지 확인 바람.
   - 미션 알림: 사용자가 정한 시각, 미션을 안 한 날만, 하루 한 번
   - 주간 점검 알림
