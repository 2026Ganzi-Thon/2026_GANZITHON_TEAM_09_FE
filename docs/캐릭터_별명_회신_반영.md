# 캐릭터 별명 회신 반영

2026-11-19 · 프론트 → 백엔드 · 받은 문서: 「프론트 회신 내용 — 캐릭터 별명 흐름 변경」(2026-11-19)

## 요약

- 회신 1~3번은 모두 반영함. 서버 변경 없이 프론트만 바뀜.
- 회신 4번(백엔드 #79)은 머지를 기다리는 중. 머지되면 프론트는 우회 코드만 지움.
- 회신에 없던 화면 결정 2개를 추가함(3절). 서버 영향 없음.

## 1. 회신 항목별 반영

| # | 회신 내용 | 반영 | 위치 |
| --- | --- | --- | --- |
| 1 | 그룹 만들 때 별명 정하기 (친구·1인 그룹) | 반영함 | `src/pages/groups/GroupCreatePage.tsx` |
| 2 | 처음 정하는 곳은 그룹 만들기뿐. 초대 코드·온라인 매칭으로 들어온 사람에게는 묻지 않음 | 반영함 (원래도 묻지 않음) | — |
| 3 | 바꾸기는 성장 과정 화면에서 나만. 기기에만 저장, 그룹 화면에는 안 보임 | 반영함 (1인 그룹 예외는 3절) | `src/pages/collection/CharacterDetailPage.tsx` |
| 4 | #79 머지 후 `GET /groups` 목록에 `characterId` → 우회 코드 삭제 | 머지 대기 | 2절 |

### 1-1. 그룹 만들기 화면

- **친구 그룹:** '친구 그룹 만들기' 시트의 그룹 이름 아래에 `캐릭터 별명 (선택)` 칸을 넣음.
- **1인 그룹:** 지금까지는 [혼자 시작하기]를 누르면 바로 만들어졌음. 이제 누르면 별명 시트가 뜨고, [시작하기]로 만듦.
- 칸은 빈칸으로 시작함. 비워 두면 별명 없이 만들어짐. 최대 10자.
- 저장: `POST /groups` 응답(`GET /groups/{id}`와 같은 모양)의 `character.characterId`로 `setCharacterNickname(groupId, characterId, 별명)`을 부름. 서버로는 보내지 않음.

### 1-2. API 확인 결과

백엔드 `docs/api.md`(main)와 PR #79를 프론트 타입(`src/api/types.ts`)과 대조함.

| API | `character.characterId` | 프론트 |
| --- | --- | --- |
| `POST /groups` | 있음 (상세와 같은 응답) | 만들기 직후 별명 저장에 씀 |
| `GET /groups/{id}` | 있음 | 성장 과정·1인 그룹 상세에서 씀 |
| `GET /groups` | 없음 → #79 머지 후 있음 | 타입은 이미 `characterId?: number`라 코드 변경 없이 받음 |

- PR #79에 "캐릭터가 완성돼 새 캐릭터로 바뀌면 값이 바뀐다"고 적혀 있음. 프론트도 별명 키를 `그룹ID:캐릭터ID`로 써서, 별명이 다음 캐릭터로 넘어가지 않음. 의도와 같음.

## 2. #79 머지 전후

| 화면 | 지금 (실서버) | #79 머지 후 |

- **요청:** #79가 머지되면 알려 주기 바람.

## 3. 회신에 없던 화면 결정 (서버 영향 없음)

1. **성장 과정 화면의 이름 순서.** 별명이 있으면 별명이 큰 이름이 되고, 원래 이름(예: '소은의 씨앗')은 위쪽 작은 표시로 내려감. 별명이 없으면 지금과 같음. 맨 위 제목은 그대로 둠.
2. **1인 그룹 상세에서는 별명을 보임.** 1인 그룹은 구성원이 나뿐이라, 그룹 상세 캐릭터 아래에 원래 이름(작게)과 별명(크게)을 보임.
   - 친구·온라인 그룹 상세에는 지금처럼 그룹 이름만 보임. 친구 그룹 캐릭터에 별명을 붙여도 나만 보는 화면(성장 과정·도감·마이·내 기록)에만 나옴.
   - 회신 3번 "그룹 화면에는 안 보임"에서 1인 그룹만 예외로 둔 것. 문제가 있으면 알려 주기 바람.
