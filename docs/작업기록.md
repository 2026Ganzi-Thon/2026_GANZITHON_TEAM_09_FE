# 행운핑 프론트엔드 작업 기록

무엇을 왜 그렇게 만들었는지 순서대로 남긴다. 기준 문서와 다르게 정한 것은 「결정 사항」에 모았다.

## 1. 첫 구현 (2026-11-15)

**기준:** 서비스 기획서 초안 + Figma 「행운핑」 앱 화면 1~10.

- Vite + React + TypeScript + React Router로 새 프로젝트를 만들었다.
- 화면 기준은 iPhone 16 Pro(393 × 852), 세로 전용이다. PC에서는 최대 430px로 가운데에 둔다.
- Figma 변수(색)와 글꼴(Jua, IBM Plex Sans KR)을 토큰으로 옮겼다.
- Figma 화면 10개를 구현했다.
  - 기분 팝업, 그룹 홈, 그룹 만들기, 그룹 상세 + 미션, 타이머, 완료·핑
  - 주간 점검, 점검 결과, 도움받기, 내 기록
- Figma에 없던 화면도 만들었다.
  - 온보딩, 마이(내 정보·알림·개인정보·고지)
  - 초대 코드, 온라인 배정 대기, 신고·차단·나가기
- 캐릭터는 참고 이미지를 바탕으로 마스코트 SVG를 그렸다. 몸은 그대로이고, 머리 위 식물이 씨앗 → 새싹 → 꽃 → 네잎클로버로 자란다. 몸 색은 3종이다.
- 백엔드가 없어서 기기 저장소(localStorage)에 목업 데이터를 두었다.

**기획서와 Figma가 달랐던 점 (A~E):**

| # | 내용 | 결정 |
| --- | --- | --- |
| A | 미션 단위: 기획서는 개인 미션, 당시 Figma는 그룹 주제 | 기획서대로 개인 미션 |
| B | 성장 표시: 기획서는 0~100 성장치, 당시 Figma는 "12 / 18회" | 기획서대로 0~100 |
| C | 빠진 날 표시: Figma에는 점선 원이 있음 | 표시하지 않음 |
| D | 홈의 오늘의 내 미션 카드: Figma에 없음 | 추가 |
| E | "그냥 하나 골라줘" 버튼: Figma에 없음 | 추가 |

## 2. 레이아웃·라우팅·성장 표시 (2026-11-16 오전)

- **세로 높이를 지정하지 않음:**
  - 최소 화면 높이(`100dvh`)를 없앴다.
  - 하단 버튼은 내용 바로 아래에 둔다 (A안).
- **앱 바깥 배경:** 흰색. PC에서는 430px 앱 영역에 테두리와 그림자를 둔다. 휴대폰에서는 바깥이 보이지 않는다.
- **가로 스크롤 방지:** `overflow-x: clip`.
- **입력창:** 글자를 16px로 올려 아이폰에서 누를 때 화면이 확대되지 않게 했다.
- **도움받을 곳 상세:** 시트 대신 `/help/:id` 경로로 바꿨다. 휴대폰 뒤로가기와 링크 공유가 된다.
- **미션 완료 결과:** 저장해 두어서 완료 화면을 새로고침해도 성장 전후가 유지된다.
- **성장 단계 표시:**
  - 단계 스텝퍼(씨앗·새싹·꽃·클로버)와 4칸 구간 막대를 넣었다.
  - 완료 화면에 성장량을 보여 준다.

## 3. 최신 문서 반영 1단계: 기반 (2026-11-16)

**기준:** PRD, api.md, UserFlow, 아키텍처, ERD, 수정된 기획서, Figma 앱 화면 1~27.

- **API 계층 (`src/api/`):**
  - api.md의 요청·응답 타입과 열거값을 그대로 옮겼다(`GOOD`·`CLOVER`·`FRIEND`…, `memberId`).
  - 같은 인터페이스를 두 가지로 구현했다.
    - `mock`: 기기 안의 가짜 서버. 응답과 에러 코드를 api.md와 맞췄다.
    - `http`: 실서버 `/api/v1`. 쿠키와 CSRF를 처리한다.
  - `VITE_API_MODE` 하나로 둘을 바꾼다. 개발 서버는 `/api`를 백엔드로 넘긴다(프록시).
- **목업 서버로 옮긴 서버 규칙:**
  - 주제 배정: 오늘 기분의 우선 주제 중에서, 최근 3일 안에 받은 주제는 뺀다.
  - 기분 매핑표: 지쳐요·우울해요면 크기를 한 단계 낮춘다.
  - 성장 계산: 확정 합 + 오늘 임시 성장. 00시에 완성 처리하고 도감에 넣는다.
  - 점검 결과 4종: `DEPRESSION`, `ANXIETY`, `LOW_MOOD_DAYS`, `STABLE`. 일요일 18시 이후에만 뜬다.
  - 초대 코드 8자·7일, 그룹 3개 제한(온라인 대기 자리 포함), 만 19세 자기 확인.
- **기기 저장소 (`src/device/`):**
  - 선택 정보 3가지(생년월일·지역·하는 일)는 IndexedDB에 두고 서버로 보내지 않는다.
  - 화면 상태(기분 팝업 띄운 날 등)는 localStorage에 둔다.
- **데이터 불러오기:** 모든 화면을 TanStack Query 훅으로 연결했다. 로딩·오류 상태를 추가했다.
- **함께 반영한 것:**
  - 기획서 미션 주제 20쌍, 밖에서/안에서 토글
  - 핑 4종: 박수·클로버·힘내·햇살. 아이콘을 새로 그렸다.
  - S11 만 19세 자기 확인 시트, 점검 결과 화면 4종
- **테스트:**
  - 규칙 테스트: PRD ID와 6절 경계값 기준
  - 목업 서버 계약 테스트: 응답 모양과 에러 코드

## 4. 스플래시·가입 흐름·감정 색 (2026-11-16)

작업 전에 프로젝트 전체를 백업했다: `D:\Todax-backup-20261116-1115`.

- **앱 실행 스플래시 (`/`):**
  - 캐릭터와 브랜드가 떠오르는 화면을 최소 1.1초 보여 준다.
  - 그동안 계정(`GET /me`)을 확인하고 자동으로 넘어간다.
- **신규 사용자 (회원가입):**
  - 순서: 시작(S01·S02) → S03 홈 화면 추가 → S04 닉네임(익명 계정 생성) → S05 → S06 → S07 알림(새 화면) → S08 첫 그룹 → 홈
  - 중간에 앱을 닫으면 다음 실행 때 멈춘 단계부터 이어서 한다.
  - 예전 로그인 화면과 소개 3장은 시작 화면 하나로 합쳤다.
- **기존 사용자:** 스플래시 → 홈. "오늘 기분은 어때요?"는 하루 한 번 뜬다.
- **감정 6색:**
  - 밝은 파스텔로 바꾸고, 감정마다 다른 색 계열을 썼다: 노랑·민트·하늘·복숭아·페리윙클·라일락.
  - 칩에 연한 감정색 배경을 깔고, 선택하면 진한 테두리와 ✓를 붙인다.

## 5. 캐릭터 도감·성장 과정 (2026-11-16)

- **마이 프로필 캐릭터:** 그룹과 상관없이 새싹으로 고정돼 있던 것을, 내 그룹 중 가장 많이 자란 캐릭터로 바꿨다. 홈과 같은 모습이다.
- **캐릭터 도감 (`/collection`):** 키우는 중인 캐릭터와 다 키운 캐릭터를 모아 보여 준다. 내 기록과 마이에서 들어간다.
- **성장 과정 (`/collection/:groupId/:characterId`):**
  - 4단계 그림, 지금 단계와 수치를 보여 준다.
  - 다 키운 캐릭터는 기간과 걸린 날 수를 보여 준다.
  - 도감, 내 기록, 그룹 상세 캐릭터에서 열린다.

## 결정 사항 (기준 문서와 다르거나 문서에 없던 것)

| 항목 | 결정 | 이유 |
| --- | --- | --- |
| 프론트 스택 | Vite 유지 (문서는 Next.js) | 처음 요청 기준. 서버 연동·쿠키·오프라인 약속은 그대로 지킴 |
| 로그인 | 없음. 닉네임 입력 = 익명 계정 생성 | PRD·UserFlow 기준 |
| 성장 표시 | Figma 문구("52.7 / 100 · 3단계") + 4칸 막대 + 상세 스텝퍼 | Figma와 사용자 피드백(단계가 보이게)을 함께 반영 |
| 핑 | `CLAP`·`CLOVER`·`MUSCLE`·`SUN` (Figma는 하트·별) | PRD·API·기획서가 같음, 서버 값과 일치 필요 |
| 감정 색 | Figma `mood/*` 변수와 다른 밝은 파스텔 | 사용자 피드백. 디자이너에게 변수 변경 요청 필요 |
| 도감 위치 | 내 기록에 두고 마이에서도 진입 | UserFlow·Figma 유지 + 사용자 의도 반영 |
| 시연 인물 | 소은, 만 26세 | UserFlow·기획서 기준 |
| 기분 흐름 | 주간 보기 (UserFlow는 '달력') | UserFlow가 "배치·디자인은 Figma가 정한다"고 함 |

## 백엔드 전달 사항

1. **필수:** `GET /missions/today`와 `POST /missions/today/start` 응답에 `minutes`, `place`, `size`를 추가해 주세요. 새로고침 후 타이머 길이와 밖/안 표시에 필요합니다.
2. **제안:** `GET /groups/{groupId}/characters/{characterId}/history` → 날짜별 누적 성장. 단계별 도달일과 성장 그래프에 씁니다.
3. **확인:**
   - `GET /me`의 `today`가 시연 시계를 따라야 기분 팝업이 맞게 뜬다.
   - 쿠키가 없으면 401을 주면 된다(프론트는 '계정 없음'으로 처리).
   - VAPID 공개키를 채워야 웹 푸시 구독이 등록된다.
   - `/help/items`에 `ETag`를 붙여 주세요.
